# Candidate improvements

These are future ideas, not available features or promised dates.

- Select a request together with its nearby failure/retry sequence
- Compare two HAR recordings around a repeated failure
- Explicit retained-field rules for common GraphQL and REST error envelopes
- Web Worker processing for larger recordings
- Import diagnostics that locate malformed entries without exposing their values

Keep offline processing, the explicit export schema, readable typography and the shared browser/CLI implementation.
